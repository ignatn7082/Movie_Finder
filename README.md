**Movie Finder** là ứng dụng web giúp bạn:

- Tìm kiếm phim cực nhanh theo tên, diễn viên, đạo diễn, thể loại
- Xem thông tin chi tiết: poster, trailer, điểm đánh giá, diễn viên, nội dung...
- Lưu danh sách phim yêu thích (Watchlist)
- Giao diện đẹp, responsive, thân thiện trên cả mobile và desktop

### 🚀 Chạy nhanh bằng Docker (khuyến nghị)

git clone https://github.com/ignatn7082/Movie_Finder.git
cd Movie_Finder
